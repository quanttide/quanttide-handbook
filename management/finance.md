# 财务管理手册

量潮工作手册管理目录下的财务管理子手册，讲的是怎么回答三件事：钱从哪里来，什么时候花，凭什么花。财务管理不是把账记完就结束，而是让预算、采购、付款、凭证和现金流预警能互相对上。

## 资金管理边界

- 日常账本、收支分类、凭证归档和月度汇总。
- 工具订阅、云资源、外包服务、差旅报销和其他经常性支出。
- 客户回款、项目预收、临时垫付和其他不稳定现金流。
- 需要把口头判断沉淀成预算规则、付款权限和复盘记录的财务决策。

## 资金使用原则

- 现金流安全优先于账面利润好看。
- 固定支出要提前知道，弹性支出要随现金流调整。
- 小额支出优先保证灵活性，大额支出优先保证审慎性。
- 长期绑定、自动续费和不可逆付款要单独评估。
- 每一笔重要支出都要能回到申请理由、审批人、付款凭证和账本记录。
- 涉及薪酬、税务、借款、利息和合规边界的安排，必须由负责人、财务和法务共同确认。

核心判断是：小团队没有专职财务，制度太复杂执行不了，没有制度又会变成创始人一人拍板。因此财务制度要在“无制度”和“过度制度”之间找平衡。

决策机制：

- 公开决议：规则通过全员会议公开决议，避免变成创始人单方面宣布。
- 记录到账本：决议内容记录到账本，便于复盘、执行和新成员对齐。
- 逐步补全：不需要一开始把所有规则定完，遇到新情况就定新规则。

## 付款责任链

- 负责人确认预算边界、付款权限和重大支出。
- 财务或记录人维护账本、凭证、分类、应收应付和周期汇总。
- 申请人说明用途、金额、周期、替代方案和不采购的影响。
- 审批人判断这笔支出是否匹配当前现金流和业务优先级。
- 执行人负责采购、付款、续费、取消和凭证回传。
- 复盘人记录超支、延期、误付、重复订阅和后续修正规则。

## 账本对象

| 对象 | 含义 |
|------|------|
| `ledger` | 账本和财务记录 |
| `cashflow` | 现金流入、流出和余额变化 |
| `budget` | 预算额度和使用边界 |
| `expense` | 支出事项 |
| `procurement` | 采购或订阅事项 |
| `approval` | 审批记录 |
| `receipt` | 发票、收据、合同或付款凭证 |
| `payable` | 应付事项 |
| `receivable` | 应收事项 |
| `rule` | 已确认的财务规则 |

## 从预算到复盘

### 建账

先把财务记录的基础结构定下来。没有账本结构时，不先讨论精细预算。

- 明确账本位置
- 明确记录字段
- 明确收入、支出和转账分类
- 明确凭证保存方式
- 明确更新频率

### 预算

预算阶段把本周期能花多少钱、必须花多少钱、可以缓一缓的钱分别说清楚。

- 估算固定支出
- 估算弹性支出
- 估算预计回款
- 预留风险缓冲
- 确认本周期可用额度

### 申请

支出申请要让审批人能判断这笔钱是不是现在必须花。

- 说明用途
- 说明金额
- 说明使用周期
- 说明替代方案
- 说明不采购的影响

### 决策

决策阶段按金额、绑定周期、可回退性和现金流压力分级。

| 类型 | 处理方式 |
|------|----------|
| 小额支出 | 一线执行人可在规则内自行决定 |
| 中额支出 | 团队负责人确认 |
| 大额支出 | 负责人或创始人确认 |
| 长期绑定 | 即使金额不大，也要单独评估 |
| 涉及薪酬、税务或借款 | 必须单独确认合规边界 |

阈值不在手册里写死，由团队按现金流规模、成本结构和风险承受能力定期调整。

分级授权表述为：

| 金额 | 决定人 |
|------|--------|
| 小额 | 一线执行人 |
| 中额 | 团队负责人 |
| 大额 | 创始人 |

核心原则是：让小决策不被阻塞，让大决策不被忽略。

### 执行

执行阶段要把付款、合同、发票、截图或收据放在同一条记录里。

- 确认付款对象
- 确认付款金额
- 确认付款时间
- 保存凭证
- 更新账本

### 复盘

复盘阶段把财务规则变成可改进的机制。

- 对比预算和实际支出
- 记录超支原因
- 记录延期付款或回款异常
- 记录采购是否继续使用
- 调整下一周期规则

## 采购决策

小额采购的核心原则是：灵活性优先于小额优惠。

适用条件：

- 优惠金额小于决策成本。
- 未来需求不确定。
- 长期绑定没有带来明确的额外价值。
- 取消、迁移或替换成本高于折扣收益。

不适用条件：

- 采购涉及关键生产系统。
- 采购会沉淀长期数据或资产。
- 采购会影响客户交付或合规要求。
- 采购合同存在自动续费、违约金或排他条款。

## 现金流预警

中小团队常见矛盾是支出刚性、收入弹性。薪酬、房租、云资源、工具订阅等支出往往按月发生，但客户回款、项目启动和大额收入存在不确定性。

这个矛盾可以称为“刚性支出 vs 弹性收入”。中小企业没有大企业常用的票据贴现、银行授信、应收账款融资等工具，因此现金流管理不是财务优化问题，而是生存问题。

现金流管理要重点看三件事：

- 未来一段时间必须支付什么。
- 未来一段时间大概率能收到什么。
- 如果回款延迟，哪些支出可以调整节奏。

可选处理方式：

- 把季度或年度付款改成月付，降低单次压力。
- 把大额采购安排在预计回款之后。
- 与供应商协商账期。
- 对非核心订阅设置复查和取消节点。
- 对薪酬、借款或利息类安排，只在负责人、财务、法务共同确认后进入正式规则。

“让刚性支出弹性化”的三种方法：

1. 按收入比例浮动：将一部分薪酬与收入挂钩；适合奖金、提成类收入，基薪部分较难浮动。
2. 延期支付：现金流紧张时，部分薪酬延期支付并计利息补偿，本质上是把工资变成有息借款。
3. 付款节奏匹配：尽量让大额支出的时间点与预计回款时间点对齐。

延期支付必须事先约定，不能事后通知。利息应高于银行理财，让员工不亏；低于借贷成本，让公司划算。适用范围也要写清，例如离职员工和在职员工是否适用。

出现以下情况时，要触发财务预警：

- 固定支出超过未来确定回款。
- 连续支出没有对应收入来源。
- 多个长期订阅同时进入续费期。
- 采购申请绕过预算或审批记录。
- 应收款延期但支出节奏没有同步调整。

## 凭证和留痕

- 财务规则要记录来源、确认人和确认时间。
- 支出申请要记录申请人、审批人、执行人和付款对象。
- 付款要保留凭证，并能对应到账本里的具体记录。
- 预算调整要记录原因、影响范围和生效时间。
- 现金流异常要记录处理方式和后续检查节点。
- 规则变更要保留旧规则、新规则和变更理由。

## 月度财务检查

- 本周期固定支出是否清楚
- 预计回款是否有更新时间
- 采购是否说明用途和期限
- 审批权限是否匹配金额和风险
- 公开决议是否已经记录到账本
- 新情况是否需要逐步补全规则
- 延期支付、利息和适用范围是否事先约定
- 凭证是否已归档
- 账本是否同步更新
- 异常是否已经复盘
