# 财务管理手册

量潮工作手册管理目录下的财务管理子手册，讲的是怎么把现金流、预算、采购、付款、记录和复盘连成一条可执行、可留痕、可审计的财务管理链路。

## 适用范围

- 适用于中小团队的日常财务管理。
- 适用于采购、订阅、报销、付款和预算控制。
- 适用于收入回款不稳定、但支出相对固定的业务场景。
- 适用于需要把创始人直觉转化为可记录规则的财务决策。

## 工作原则

- 先保现金流，再看账面利润。
- 小金额决策优先保证灵活性，大金额决策优先保证审慎性。
- 规则要事先约定，不能事后补口径。
- 每一笔重要支出都要能说明原因、负责人和凭证。
- 财务决策要记录到账本或任务系统里，方便复盘。
- 涉及薪酬、税务、借款、利息和合规边界的安排，必须由负责人、财务和法务共同确认。

## 角色分工

- 负责人负责确认财务规则、预算边界和重大支出。
- 财务或记录人负责维护账本、凭证、分类和周期性汇总。
- 申请人负责说明支出目的、金额、期限和替代方案。
- 审批人负责按权限判断是否同意支出。
- 执行人负责采购、付款、续费和取消。
- 复盘人负责记录执行结果、异常和后续改进。

## 关键对象

| 对象 | 含义 |
|------|------|
| `ledger` | 账本和财务记录 |
| `cashflow` | 现金流入、流出和余额变化 |
| `budget` | 预算额度和使用边界 |
| `expense` | 支出事项 |
| `procurement` | 采购或订阅事项 |
| `approval` | 审批记录 |
| `receipt` | 发票、收据、合同或付款凭证 |
| `payable` | 应付事项 |
| `receivable` | 应收事项 |
| `rule` | 已确认的财务规则 |

## 工作链路

### 建账

先把财务记录的基础结构定下来。

- 明确账本位置
- 明确记录字段
- 明确收入、支出和转账分类
- 明确凭证保存方式
- 明确更新频率

### 预算

预算阶段把可用资金和支出边界说清楚。

- 估算固定支出
- 估算弹性支出
- 估算预计回款
- 预留风险缓冲
- 确认本周期可用额度

### 申请

支出申请要让审批人能判断值不值得花。

- 说明用途
- 说明金额
- 说明使用周期
- 说明替代方案
- 说明不采购的影响

### 决策

决策阶段按金额和风险分级。

| 类型 | 处理方式 |
|------|----------|
| 小额支出 | 一线执行人可在规则内自行决定 |
| 中额支出 | 团队负责人确认 |
| 大额支出 | 负责人或创始人确认 |
| 长期绑定 | 即使金额不大，也要单独评估 |
| 涉及薪酬、税务或借款 | 必须单独确认合规边界 |

阈值不在手册里写死，由团队按现金流规模、成本结构和风险承受能力定期调整。

### 执行

执行阶段要把付款和凭证放在同一条记录里。

- 确认付款对象
- 确认付款金额
- 确认付款时间
- 保存凭证
- 更新账本

### 复盘

复盘阶段把财务规则变成可改进的机制。

- 对比预算和实际支出
- 记录超支原因
- 记录延期付款或回款异常
- 记录采购是否继续使用
- 调整下一周期规则

## 采购决策

小额采购的核心原则是：灵活性优先于小额优惠。

适用条件：

- 优惠金额小于决策成本。
- 未来需求不确定。
- 长期绑定没有带来明确的额外价值。
- 取消、迁移或替换成本高于折扣收益。

不适用条件：

- 采购涉及关键生产系统。
- 采购会沉淀长期数据或资产。
- 采购会影响客户交付或合规要求。
- 采购合同存在自动续费、违约金或排他条款。

## 现金流管理

中小团队常见矛盾是支出刚性、收入弹性。薪酬、房租、云资源、工具订阅等支出往往按月发生，但客户回款、项目启动和大额收入存在不确定性。

现金流管理要重点看三件事：

- 未来一段时间必须支付什么。
- 未来一段时间大概率能收到什么。
- 如果回款延迟，哪些支出可以调整节奏。

可选处理方式：

- 把季度或年度付款改成月付，降低单次压力。
- 把大额采购安排在预计回款之后。
- 与供应商协商账期。
- 对非核心订阅设置复查和取消节点。
- 对薪酬、借款或利息类安排，只在负责人、财务、法务共同确认后进入正式规则。

## 留痕要求

- 财务规则要记录来源和确认时间。
- 支出申请要记录申请人、审批人和执行人。
- 付款要保留凭证。
- 预算调整要记录原因。
- 现金流异常要记录处理方式。
- 规则变更要保留旧规则和新规则。

## 快速检查

- 本周期固定支出是否清楚
- 预计回款是否有更新时间
- 采购是否说明用途和期限
- 审批权限是否匹配金额和风险
- 凭证是否已归档
- 账本是否同步更新
- 异常是否已经复盘
