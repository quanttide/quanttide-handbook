# 云计算手册

量潮工作手册研发目录下的云计算子手册，讲的是怎么把函数计算、云存储、工作流编排、Web 框架和 SaaS 集成连成一条可执行、可审计、可复用的工程链路。

## 适用范围

- 适用于函数计算、Serverless Framework 和云函数项目。
- 适用于需要把云资源、配置、凭据、发布和运维统一管理的项目。
- 适用于需要对象存储、文件存储、数据库、缓存等状态资源协同工作的场景。
- 适用于会议、协作、数据处理等 SaaS 能力接入云端工作流的场景。

## 工作原则

- 先定业务场景，再选云服务。
- 先定资源边界，再写业务代码。
- 代码、配置、凭据和文档要同步治理。
- 开发环境、测试环境和生产环境要明确区分。
- 云资源变更要能追溯，发布结果要能回退。

## 目录地图

| 章节 | 内容 |
|------|------|
| 项目框架 | 函数计算项目的目录、配置和文档约定 |
| DevOps流程 | Serverless Framework、CI、凭据和环境变量 |
| 有状态 | 缓存、数据库、对象存储和文件存储 |
| 工作流编排 | 多步骤任务、爬虫、自动化测试和数据分析 |
| 层管理 | 公共依赖、共享运行时和复用策略 |
| Web框架 | Django 等 Web 框架在云函数中的使用 |
| 会议 | 腾讯会议等 SaaS 场景的接入规范 |

## 交付标准

- 有清晰的项目结构和入口文件。
- 有可复现的环境变量、凭据和资源配置说明。
- 有构建、部署、调试和验收步骤。
- 有云资源命名、权限和隔离规则。
- 有日志、监控、回退和故障处理记录。

## 快速检查

- 资源名称是否带项目和环境标识
- 环境变量是否未提交到 Git
- 凭据是否走受控的 CI 或密钥管理
- 云函数入口和依赖是否明确
- 数据库、存储和网络是否完成隔离
- 部署后是否能验证访问和回退
